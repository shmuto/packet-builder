# レイヤーを編集する画面を作る
## 目的

ブラウザ上でレイヤーの値を入力し、組み立てたパケットを確認できるようにします。

## 作るもの

- Ethernet / IPv4 / UDP の入力フォーム。上から順に積み木のように並べる
- ペイロードの入力欄。テキストと 16 進の切り替えができる
- 組み立てたパケットの 16 進ダンプ表示
- 自動で決まる値の欄には「自動」の表示を付け、手動入力に切り替えられるようにする

## 受け入れ条件

- 入力を変えると、すぐに 16 進ダンプが更新される
- 入力が不正なときは、該当する欄の近くにエラーを表示する。画面は壊れない
- 計算は `src/core/` の関数を呼ぶだけにして、UI 側に計算を書かない
- 初期値として、そのまま正しいパケットになる値を入れておく
- `npm run check` が成功する
