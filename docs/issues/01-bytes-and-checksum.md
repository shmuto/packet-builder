# バイト列の基本関数とチェックサムを作る
## 目的

パケットを組み立てる前に、土台になる関数を `src/core/` に用意します。

## 作るもの

- `parseMac(text)`：`aa:bb:cc:dd:ee:ff` 形式の MAC アドレスを 6 バイトに変換する
- `parseIPv4(text)`：`192.168.0.1` 形式の IPv4 アドレスを 4 バイトに変換する
- `internetChecksum(bytes)`：RFC 1071 のインターネットチェックサムを計算する
- `toHexDump(bytes)`：16 バイトごとに改行し、行頭にオフセットを付けた 16 進ダンプを返す

## 受け入れ条件

- 変換に失敗したときは、例外ではなくエラー内容を返す
- すべての関数にテストがある
- `npm run check` が成功する

## テストで確認すること

- MAC アドレス：大文字と小文字の両方を受け付ける。区切りが足りない、桁が多い、16 進以外の文字を含む場合はエラーになる
- IPv4 アドレス：`0.0.0.0` と `255.255.255.255` は正常。`256.0.0.1`、`1.2.3`、`01.2.3.4`、空文字はエラーになる
- チェックサム：RFC 1071 の例と一致する。奇数長のデータは末尾に 0x00 を足して計算する。正しいチェックサムを埋めたデータを再計算すると 0 になる
- 16 進ダンプ：空のデータ、ちょうど 16 バイト、17 バイトの 3 パターン
