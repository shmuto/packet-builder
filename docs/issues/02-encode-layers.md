# Ethernet / IPv4 / UDP のヘッダを組み立てる
## 目的

各レイヤーの入力値から、パケット全体のバイト列を作れるようにします。

## 作るもの

- Ethernet II、IPv4、UDP の各レイヤーを表す型
- レイヤーの配列とペイロードを受け取り、バイト列を返す `buildPacket(layers, payload)`

## 自動で決める値

次の値は自動で計算します。ただし、利用者が手動で値を指定したときはそちらを優先します。

- Ethernet の EtherType：上が IPv4 なら `0x0800`
- IPv4 の全長、プロトコル番号（UDP なら 17）、ヘッダチェックサム
- UDP の長さ、チェックサム（擬似ヘッダを含めて計算する）

## 受け入れ条件

- IPv4 のオプションは扱わない。IHL は常に 5 とする
- 対応していないレイヤーの順番（例：UDP の上に IPv4）は、エラー内容を返す
- 生成したバイト列が、Wireshark などで正しく読める形になっている
- `npm run check` が成功する

## テストで確認すること

- 既知の正しいパケットを 1 つ用意し、バイト単位で完全に一致する
- ペイロードが 0 バイトのときも正しく組み立てられる
- UDP のチェックサムの計算結果が 0 になる場合は、RFC 768 に従い 0xffff を入れる
- 手動で指定した値が、自動計算の値より優先される
- IPv4 の全長が 65535 を超える場合はエラーになる
