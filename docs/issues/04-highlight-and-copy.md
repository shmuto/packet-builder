# フィールドとバイトの対応を表示し、コピーできるようにする
## 目的

どの入力欄がパケットのどのバイトになるのかを、目で見て分かるようにします。

## 作るもの

- 入力欄にマウスを乗せると、16 進ダンプの対応するバイトを強調表示する
- 逆に、16 進ダンプのバイトにマウスを乗せると、対応する入力欄を強調表示する
- 組み立てたバイト列を、空白なしの 16 進文字列としてコピーするボタン

## 受け入れ条件

- フィールドとビット範囲の対応表は `src/core/` で作り、テストする
- 4 ビット単位のフィールド（IPv4 の バージョンと IHL など）は、そのフィールドを含むバイトを強調する
- `npm run check` が成功する

## テストで確認すること

- 対応表のビット範囲が、隙間なく、重なりなくパケット全体を覆っている
- 4 ビット単位のフィールドが、正しいビット範囲とバイトに対応している
